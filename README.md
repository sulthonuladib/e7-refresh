# E7 Secret Shop Refresh (Go / MyGo)

A cross-platform rewrite of [Epic-Seven-E7-Secret-Shop-Refresh](https://github.com/sya1999/Epic-Seven-Secret-Shop-Refresh)
in Go with [MyGo](https://github.com/egoist/mygo). It refreshes the Epic Seven
secret shop using either host mouse control or ADB, and lives in the system tray
(or the Omarchy bar) instead of a permanent window.

> This repository is a work in progress. The full README with build and
> installation instructions is written as the implementation lands.
